# Learning

Обучение: курсы, заметки, исходные материалы, практика и планы в одном месте.

## Структура

| Папка | Содержимое |
| --- | --- |
| [Курсы](Курсы/) | Учебные программы, прохождение курсов и прогресс по урокам. |
| [Заметки](Заметки/) | Конспекты, выводы и вопросы по изученным темам. |
| [Материалы](Материалы/) | Исходные учебные материалы, документы и ссылки на источники. |
| [Практика](Практика/) | Упражнения, решения задач и учебные проекты. |
| [Планы](Планы/) | Цели обучения, расписание и списки следующих шагов. |

## Как пользоваться

1. Запишите цели и ближайшие шаги в «Планы».
2. Создайте папку по названию курса или темы в подходящих разделах.
3. Сохраняйте исходные материалы в «Материалы», конспекты — в «Заметки», а собственные решения — в «Практика».
4. Отмечайте прогресс в «Курсы» и обновляйте планы по мере обучения.

Пишите по-русски и сохраняйте исходные материалы без изменений; для обработки используйте копии. Завершённые изменения отправляйте на GitHub отдельными коммитами. Правила для помощников описаны в [AGENTS.md](AGENTS.md).

Файлы `.gitkeep` сохраняют пока пустые папки в Git. Для работы с документами установка зависимостей и запуск сервисов не требуются.
