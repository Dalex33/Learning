# Правила работы

- Писать по-русски: ответы, документацию, сообщения коммитов и описания pull request.
- Сохранять исходные материалы. Не удалять и не перезаписывать оригиналы; для переработки создавать отдельные копии, сохраняя ссылки на источники, если они известны.
- Отправлять завершённые изменения на GitHub отдельными коммитами: один логически завершённый набор изменений — один коммит с понятным описанием.
